# Galeri Kartu

Galeri responsif berisi kartu warna dengan filter kategori dan jendela detail (modal).

## Fitur
- Tampilan grid yang menyesuaikan lebar layar (CSS Grid)
- Filter kategori: Semua, Alam, Kota, Makanan
- Klik kartu untuk melihat detail di jendela modal
- Modal bisa ditutup dengan tombol, klik area gelap, atau tombol Esc
- Elemen bisa dioperasikan dengan keyboard

## Teknologi
HTML, CSS (Grid, Flexbox), JavaScript (tanpa framework)

## Cara menjalankan
Unduh folder ini, lalu buka `index.html` di peramban. Tidak perlu instalasi apa pun.

## Yang saya pelajari
- Menampilkan data dari array ke halaman dengan DOM
- Membuat filter dengan `filter` dan `Set`
- Membuat modal sederhana dan mengatur fokus keyboard
- Tata letak responsif dengan `grid-template-columns: repeat(auto-fill, ...)`
